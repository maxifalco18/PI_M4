--------------------------------------------------------------------------------
PASO 2: INSTALAR DOCKER Y DOCKER COMPOSE EN LA EC2
--------------------------------------------------------------------------------
Una vez conectado, copia y pega estos comandos uno por uno en la terminal de ubuntu:

# Actualiza el sistema
sudo apt update && sudo apt upgrade -y

# Instala Docker de forma rápida
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

# Da permisos a tu usuario 'ubuntu' para ejecutar Docker sin escribir 'sudo'
sudo usermod -aG docker ubuntu

# Instala Docker Compose
sudo apt install docker-compose-plugin -y

# IMPORTANTE: Escribe 'exit' para salir de la máquina, y luego vuelve a 
# conectarte con el comando ssh del Paso 1. Si no lo haces, Docker te dará error de permisos.

--------------------------------------------------------------------------------
PASO 3: PREPARAR EL ENTORNO DE AIRFLOW EN LA EC2
--------------------------------------------------------------------------------
Crea la carpeta de tu proyecto en la EC2:

mkdir -p /home/ubuntu/airflow/{dags,logs,plugins}
cd /home/ubuntu/airflow

# Mapea el usuario de Airflow (UID 50000)
echo -e "AIRFLOW_UID=50000" > .env

--------------------------------------------------------------------------------
PASO 4: SUBIR EL ARCHIVO DOCKER-COMPOSE Y LOS DAGS
--------------------------------------------------------------------------------
1. Abre una NUEVA pestaña en tu terminal de Windows local (sin cerrar la de la EC2).

4. Transfiere tu carpeta de DAGs para que Airflow pueda orquestar el pipeline:
